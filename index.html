portafolio de proyectos

proyectos

Estos proyectos muestran mi enfoque para resolver retos de usabilidad a través de investigación, diseño de interfaces y recorridos de usuario estructurados. Son proyectos independientes, de iniciativa propia, creados para practicar y refinar mis habilidades de prototipado.

01

primer
proyecto

EanMob — Plataforma de Movilidad Compartida Sostenible

Contexto

EanMob es una plataforma móvil diseñada para conectar estudiantes de la Universidad EAN que comparten rutas de desplazamiento. El objetivo es reducir el tráfico, disminuir emisiones de carbono y crear comunidad universitaria a través de la movilidad sostenible.

Mi rol

  • Flujo de búsqueda y publicación de viajes
  • Pantalla de inicio de sesión y creación de cuenta
  • Diseño del formulario con validación de errores
  • Jerarquía visual clara y elementos de confianza
02

segundo
proyecto

Dotech — Radicador Documental Inteligente

Contexto

Dotech (Edotech) es una plataforma de gestión documental para entidades públicas colombianas. Permite radicar, asignar y hacer seguimiento de documentos con control de vencimientos, trazabilidad completa y auditoría integrada.

Mi rol

  • Rediseño del flujo de radicación y seguimiento
  • Pantalla de inicio de sesión institucional
  • Panel de control con estados (En Gestión, Asignado, En Revisión)
  • Dashboard con métricas y tabla de radicados
03

tercer
proyecto

Fundación Ramírez Moreno — Rediseño Web

Contexto

Rediseño completo del sitio web de la Fundación Ramírez Moreno, una organización social que apoya instituciones colombianas a través de proyectos, donaciones y fortalecimiento institucional. El trabajo incluyó diagnóstico UX, arquitectura de información y sistema de diseño.

Mi rol

  • Sistema de diseño con paleta de color y tipografía
  • Flujos de usuario para organizaciones postulantes
  • Rediseño de páginas: inicio, líneas de apoyo e inscripciones
  • Mejoras de accesibilidad y arquitectura de información
04

cuarto
proyecto

GrowLink × Avellanedas Go — Sistema de Diseño y Sitio Web

Contexto

GrowLink es una plataforma de reseñas para negocios locales. Avellanedas Go es una panadería artesanal en La Calera, Cundinamarca. El proyecto implicó construir un sistema de diseño completo para GrowLink y diseñar el sitio web de Avellanedas Go como caso de uso real.

Mi rol

  • Definición de tokens de color, tipografía y componentes
  • Diseño de componentes: formularios, navegación, tarjetas
  • Sitio web de Avellanedas Go: inicio y página de menú
  • Integración de identidad de marca artesanal al sistema digital
